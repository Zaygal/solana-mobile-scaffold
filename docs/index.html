One round a day. Sealed with your wallet.

An app that keeps your streak can fake it. Clock In turns it into a record: the streak is recomputed from Solana on every launch, and there is no local state to lie about.

Download the APK Source on GitHub

How it works

  • One round a day costs a ten-second hold.
  • That round is sealed as a signed Solana devnet transaction from your own wallet.
  • The record is a versioned, positionally-decoded memo — date, act, measured hold, sample interval, attestation method.
  • The streak is recomputed by reading that wallet's on-chain history. Nothing is trusted from local storage.
  • A dependency-free verifier (377 lines, no dependencies) rechecks any record on your own machine.

Why a memo, not a transfer

A token amount would make your record depend on that token continuing to exist. A memo is readable from the transaction alone, forever, by anyone — and this app never holds funds.

What it does not prove

The ten-second hold is self-reported: no camera, no sensor, no witness. The app says so on its own limits screen rather than leaving it for you to discover. It is not a fitness tracker.

Status: devnet only. Zero users, zero revenue. Built for Android on the official Mobile Wallet Adapter, with bare React Native (no Expo). Eligibility is gated on the Seeker Genesis Token, not the device model — an emulator and a Seeker run identical code.
